# backend-chat 기능명세서 (채팅 서비스)

> 팀 기능명세서 중 채팅 서비스 담당 범위(No.23~25)만 정리한다.
> 이벤트 스토밍 반영본 기준이다.

| No. | 역할 | 화면구분 | 기능 이름 | 요구사항 설명 | 비고 | 개발 구분 |
|---|---|---|---|---|---|---|
| 23 | 구매자/판매자 | 채팅 | 채팅방 생성 | - 상품 판매글 내 버튼(채팅하기)으로 채팅방 생성<br>- 상대 유저와 최초 대화 시 생성<br>- 상품 상태에 상관없이 채팅 생성 가능<br>- 1대1로만 생성 가능<br>- 정지된 유저는 채팅방 생성 불가<br>- 메시지를 보내지 않으면 채팅방을 생성하더라도 채팅방 목록에 뜨지 않음 (자동 메시지 전송 안 함) | 회원만 접근 가능 | 상 |
| 24 | 구매자/판매자 | 채팅 | 채팅 | - 사진 및 동영상은 최대 10개 첨부 가능<br>- 사진 형식: png, jpg, jpeg / 동영상 형식: mp4, mov<br>- 1초마다 5회 연속 채팅 전송 시 채팅 10초 정지<br>- 채팅 내 사진·동영상은 최대 3개월까지 DB 저장<br>- 외부결제, 개인정보 전송 시 경고 메시지 전송<br>- 구매자가 구매하기 버튼을 누르면 판매자에게 수락 여부를 묻는 채팅 자동 발송<br>- 판매자가 수락하기 버튼을 누르면 구매자에게 결제 채팅 자동 발송<br>- 메시지마다 번역하기 버튼 제공<br>- 언어 변경 시 실채팅을 제외한 모든 언어 부분이 변경된 언어로 바뀜 | MongoDB로 설계<br>번역: Google / DeepL / Papago / Azure 후보<br>회원만 접근 가능 | 상 |
| 25 | 구매자/판매자 | 채팅 | 채팅방 나가기 | - 채팅방은 soft delete (영구)<br>- 채팅방 나가기 버튼을 누르면 모달을 띄움<br>- 채팅방을 나가면 채팅방을 선택하라는 문구가 뜸 | 회원만 접근 가능 | 상 |

## 파생 조회 기능

| 기능 이름 | 요구사항 설명 | 비고 |
|---|---|---|
| 채팅방 목록 조회 | - 내가 참여 중이며, 메시지가 1건 이상 존재하는 채팅방만 노출<br>- 최근 메시지·상대 정보 표시 | No.23 목록 미노출 규칙과 연동 |
| 메시지 목록 조회 | - 채팅방 메시지 이력 조회 | 참여자만 접근 가능 |

## 서비스 경계 (본 서비스 범위 밖)

| No. | 기능 | 비고 |
|---|---|---|
| 26 | 판매자 정보 입력 | 구매/정산 흐름. 채팅에서 진입할 수 있으나 입력·저장은 타 서비스 |
| 27~30 | 알림 | 알림 서비스 담당. 채팅 알림 배지는 알림/프론트 연동 |

## 구현 단계 메모

- MongoDB Document·컬렉션 설계는 DB 확정 후 반영한다.
- WebSocket 등 실시간 전송, 번역 API 연동, 미디어 업로드는 DB·API 확정 후 단계적으로 구현한다.
