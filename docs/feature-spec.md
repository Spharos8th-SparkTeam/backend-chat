# backend-chat 기능명세서 (채팅 서비스)

| No. | 역할 | 화면구분 | 기능 이름 | 요구사항 설명 | 비고 | 개발 구분 |
|---|---|---|---|---|---|---|
| 1 | 구매자/판매자 | 채팅 목록 | 채팅방 목록 조회 | - 내가 참여 중인 채팅방 목록 조회<br>- 최근 메시지·상대 정보 표시 | 회원만 접근 가능 | 상 |
| 2 | 구매자/판매자 | 채팅 목록 | 채팅방 생성 | - 거래 상대와 채팅방 생성<br>- 이미 있으면 기존 방 반환 | 거래 당사자만 접근 가능 | 상 |
| 3 | 구매자/판매자 | 채팅방 | 메시지 목록 조회 | - 채팅방 메시지 이력 조회 | 참여자만 접근 가능 | 상 |
| 4 | 구매자/판매자 | 채팅방 | 메시지 전송 | - 텍스트 메시지 전송 | 참여자만 접근 가능 | 상 |

> 화면/API 세부 사항은 개발 진행에 따라 갱신한다.
> MongoDB Document·컬렉션 설계는 DB 확정 후 반영한다.
> WebSocket 등 실시간 전송은 별도 단계에서 추가한다.
